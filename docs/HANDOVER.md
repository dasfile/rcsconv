# Передача проекта (handover)

Короткая точка входа для нового диалога/агента. Подробности — в `PLAN.md`,
`docs/RCS-FORMAT.md` и `docs/RCP-FORMAT.md`.

## Что это за проект

Реверс-инжиниринг форматов Autodesk ReCap: контейнер `.rcs` (сигнатура `ADOCT`,
эталонная версия ReCap **2020 / 6.0.0.110**) и проект `.rcp`. Цель — обратимый
читатель и писатель `.rcs`, проверяемый Revit. Рабочий каталог: **`C:\dev\rcsconv`**.

## Следующая задача

Обязательных задач нет: `.pts`/`.laz` → `.rcs` работает и принято Revit 2023.
Открытые вопросы («на понимание») — `docs/RCS-FORMAT.md` §12; самое интересное:

1. **децимация экспорта**: потери ReCap похожи на сетку ≈5 мм, но точный шаг и
   начало сетки не подобраны (числа — `docs/CORPUS.md`);
2. **байты тела `[12]`, `[13]`**: в корпусе не нули (0…255 и 0…4) — смысл открыт;
3. **правило байта `[8]`**: значение / 255 / высотный градиент / мусор — нужен скан
   с реальной интенсивностью;
4. `kind 0…7` в заголовке payload'а, поля записи узла `@96…`, `tail_u32`;
5. `count` заголовка vs сумма по узлам (+0…+91);
6. `.rcp`: `PointCloudSegmentList`, `Color`, `bk1…bk3` (`docs/RCP-FORMAT.md` §5).

## Про данные

Всё в одной папке **`golden/`** (в git не входит, ~1.6 ГБ):

- корень — ветка **из `.pts`**: `<имя>.laz` (iPhone/Polycam), `<имя>.pts`
  (`las2pts.py`), `<имя>.rcp`, экспорт `<имя>.rcs`, raw `<имя> Support/<имя>.rcs`;
- `golden/lazimport/` — ветка **из `.laz`** (два облака, импорт без `.pts`);
- `golden/reference/*_orig.rcs` — импорты 2026-10-29: на них держится побайтовое
  доказательство писателя (наш файл отличается только GUID и байтами интенсивности);
- `golden/MANIFEST.sha256` — SHA-256 всех данных.

Результаты своих прогонов писать в **`out/`**, эксперименты — в `dumps/`.

## Чего не делать

- Не менять `golden/**` (это эталоны) и `reference/*_orig.rcs`.
- Не подгонять байты под ожидаемый размер и не хардкодить куски дампа.
- Не возвращать писателю зависимость от `.rcs`-шаблона (`.clinerules` п.14).
- Не генерировать синтетические облака и не импортировать их в ReCap: импортёр
  отвергает часть без внятной причины (лог пуст) — направление закрыто, см. PLAN.md.
