# Передача проекта (handover)

Короткая точка входа для нового диалога/агента. Подробности — в `PLAN.md`,
`docs/RCS-FORMAT.md` и `docs/RCP-FORMAT.md`.

## Что это за проект

Реверс-инжиниринг форматов Autodesk ReCap: контейнер `.rcs` (сигнатура `ADOCT`,
эталонная версия ReCap **2020 / 6.0.0.110**) и проект `.rcp`. Цель — обратимый
читатель и писатель `.rcs`, проверяемый Revit. Код — Python 3.11 (stdlib + `numpy`);
`laspy` нужен только для LAS/LAZ. Целевой продукт — автономный `rcsconv.exe` на
Rust (`docs/ROADMAP.md`); Python остаётся эталоном и оракулом.

## Следующая задача

**R3: чтение `.rcs` в Rust** (`docs/ROADMAP.md`) — подкоманды `rcs2pts` и `inspect`
поверх готового `rcs-format` (контейнер, узлы, тела точек уже портированы и
проверены). Приёмка — те же точки, индексы и bbox, что у Python (`tools/rcs2pts.py`,
`tools/rcs_inspect.py`). Дальше R5: финальные замеры и публикация `.exe`.

Готово до этого: `.las/.laz` → `.rcs` (`las2rcs`) и `.pts` → `.rcs` (`pts2rcs`)
в Rust — паритет с Python на `level_7` (324 680 точек, 43 узла) **побайтово, кроме
GUID**; 0.7 с против 11.2 с у Python, `.exe` 604 КБ статически.

Python-реализация по приёмке закрыта и с критического пути снята: она эталон и
оракул для паритетных тестов, а также среда исследования §12. Оптимизация Python
(`numpy`, скорость) **не планируется** — цель задаётся в Rust.

Открытые вопросы «на понимание» — `docs/RCS-FORMAT.md` §12: децимация экспорта
(сетка ≈5 мм), байты тела `[8]`/`[12]`/`[13]`, `kind 0…7`, поля записи узла
`@96…`, `count` заголовка против суммы по узлам. Ветка `.e57` отложена
(`docs/CORPUS.md`); плагин Revit ждёт материалы владельца.

## Про данные

Данные в git не входят: эталоны созданы Autodesk и снимаются локально (`golden/`,
`docs/CORPUS.md`). В `golden/` лежат `.laz/.pts`, проекты `.rcp`, эталоны `.rcs`,
raw `Support/*.rcs`, вторая ветка `lazimport/` и `reference/*_orig.rcs`.
Результаты прогонов — в `out/`, эксперименты — в `dumps/`.

## Чего не делать

- Не менять `golden/**` и `golden/reference/*_orig.rcs`.
- Не подгонять байты под ожидаемый размер и не хардкодить куски дампа.
- Не возвращать писателю зависимость от `.rcs`-шаблона (`.clinerules` п.14).
- Не импортировать в ReCap синтетические облака: направление закрыто (`PLAN.md`).
