ReCap `.rcs` reader/writer - without ReCap and without a template.

## Downloads
- `rcsconv-1.0.1-x86_64-pc-windows-gnu.zip` - CLI `rcsconv.exe`, GUI
  `rcsconv-gui.exe`, `rcsconv.dll`, Revit sources (`revit/`), `SHA256SUMS.txt`.
- `rcsconv-revit-1.0.1.zip` - Revit 2023 add-in: `RcsConv.addin` +
  `rcsconv/RcsConvRevit.dll` + `rcsconv/rcsconv.dll`.

## Highlights
- `.pts`, `.las`, `.laz` -> `.rcs` (Unified RCS v5), byte-identical to the
  reference implementation; `read -> write` is byte-exact on the corpus.
- One Rust core compiled into three independent artifacts: the CLI and the GUI
  are static and load no DLLs; `rcsconv.dll` (C ABI) is used only by the add-in.
- Adaptive memory: in-memory below the budget (`--memory-budget`, default 2 GB),
  streaming above it; about 20 MB peak in streaming mode.
- Parallel: rayon for octree/grouping/encoding, parallel LAZ decompression, and
  batches of files; about 2x faster on 4M points.
- GUI: native Win32, English.
- Revit add-in: converts and links point clouds; falls back to the built-in C#
  writer for `.pts` when `rcsconv.dll` is missing.

## Install (Revit add-in)
Unpack `rcsconv-revit-1.0.1.zip` into
`%APPDATA%\Autodesk\Revit\Addins\2023` and restart Revit:
Add-Ins -> External Tools -> "rcsconv - Point Cloud".

## Known limits
- `.e57` is deferred (no valid sample file in the corpus).
- `.laz` in the add-in requires `rcsconv.dll` (shipped in the archive).
- The Python tools in `tools/` are the reference implementation and still require
  `-f` to overwrite.
